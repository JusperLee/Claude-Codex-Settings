# ccsync Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 构建一个通过 SSH/rsync 双向同步 Codex 与 Claude Code 配置、可选聊天历史并保留远端独立密钥的 Python CLI。

**Architecture:** CLI 从 JSON 配置读取远端信息，用 rsync 修改时间规则同步普通文件；少量混合配置文件在本地临时目录中做敏感字段合并。认证文件仅使用 `--ignore-existing` 初始化远端，不建立内容哈希或远端探针。

**Tech Stack:** Python 3.10+ 标准库、OpenSSH、rsync、unittest

---

### Task 1: 建立包与配置模型

**Files:**
- Create: `pyproject.toml`
- Create: `src/ccsync/__init__.py`
- Create: `src/ccsync/config.py`
- Test: `tests/test_config.py`

**Steps:**
1. 编写配置初始化、保存、读取和远端增删的精简测试。

3. 实现 JSON 配置文件与 `Remote` 数据模型，使用临时文件原子保存并设置 `0600`。
4. 再次运行测试，确认通过。
